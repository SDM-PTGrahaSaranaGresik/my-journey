PRIVASI & KENDALI

Your stories, your space. ♡

Diary ini dirancang untuk menjaga cerita pribadimu tetap berada dalam kendalimu.

Unduh cadangan terenkripsi

Simpan file cadangan pribadi. Untuk memulihkan jurnal, kamu tetap perlu mengingat kata sandi yang dipakai saat cadangan dibuat.

Pulihkan dari cadangan

Memulihkan cadangan mengganti catatan yang ada di browser ini. Semua data dalam cadangan tetap terenkripsi.

Kunci diary

Setiap kali membuka kembali halaman, masukkan kata sandi untuk membaca catatan.

Hapus semua data perangkat

Menghapus catatan, curhat, dan draf dari browser ini. Tidak dapat dibatalkan tanpa file cadangan.

Penting tentang penyimpanan

Data disimpan hanya di browser tempat kamu membuka situs ini. Tidak ada sinkronisasi otomatis antarperangkat, tidak ada akun cloud, dan tidak ada pengiriman isi jurnal ke pembuat situs. Hapus data situs/browser atau berganti HP bisa menghapus jurnal. Buat cadangan terenkripsi secara berkala.

Untuk memasang sebagai aplikasi di layar utama HP, situs perlu dibuka melalui alamat HTTPS. Di iPhone gunakan menu Safari → Bagikan → Tambah ke Layar Utama; di Android gunakan menu Chrome → Tambahkan ke Layar Utama / Instal aplikasi.
